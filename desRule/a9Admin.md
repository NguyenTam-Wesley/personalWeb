# RHODES_ISLAND_CONTROL_AUTHORITY_RULES.md

# DESIGN OBJECTIVE

Transform the Admin page into the Rhodes Island Control Authority.

The page should resemble a high-level administrative console used by Rhodes Island system administrators.

Users are not managing a website.

Users are supervising and controlling an operational network.

This is:

* Central Administration Console
* System Control Authority
* Network Management Center
* Administrative Operations Hub

This is NOT:

* Generic Admin Dashboard
* SaaS Control Panel
* CMS Backend
* Analytics Dashboard
