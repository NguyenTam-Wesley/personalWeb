# RHODES_ISLAND_PERSONNEL_MODIFICATION_TERMINAL_RULES.md

# DESIGN OBJECTIVE

Transform the Edit Profile page into the Rhodes Island Personnel Modification Terminal.

The page should resemble an internal administrative interface used to update operator personnel records.

Users are not editing a social profile.

Users are updating official operator information stored within the Rhodes Island network.

This is:

* Personnel Modification Terminal
* Operator Record Maintenance
* Personnel Data Update Interface
* Identity Record Editor

This is NOT:

* Edit Profile Page
* Account Settings Page
* Social Profile Editor
* User Dashboard
